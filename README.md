# TorqueLab Auto Care — Automotive Service Center Website

A modern, responsive website concept for an automotive service and repair center. Built with semantic HTML, custom CSS, and vanilla JavaScript.

## Live Demo

[View the live website](https://mkaceduet-hub.github.io/automotive-service-center-website/)

## Project Features

- Bold automotive-inspired visual identity and responsive layout
- Mobile-friendly navigation
- Service overview for maintenance, diagnostics, brakes, tyres, AC, and inspections
- About, workshop process, contact, and appointment sections
- Appointment request form with front-end validation and demo feedback
- SEO-friendly page title, description, and semantic structure
- Accessible labels, focus states, and reduced-motion support
- No framework or build step required

## Technologies

- HTML5
- CSS3 (Grid, Flexbox, responsive media queries)
- Vanilla JavaScript

## Project Files

- `index.html` — website structure and content
- `style.css` — visual design and responsive styles
- `script.js` — navigation and appointment form interactions

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Sublime Text.
3. Open `index.html` in a modern browser.
4. Visit the live demo using the link above.

## Important Customization Notes

- **Demo brand:** TorqueLab Auto Care is a fictional portfolio concept.
- **Contact details:** The phone number and email address are placeholders. Replace them with real business details.
- **Appointment form:** The form currently demonstrates client-side interaction only. Connect it to a secure backend or form service before using it to receive real customer requests.
- **Location panel:** Replace the illustrative map graphic with the actual workshop address or an embedded map when deploying for a real business.
- **Images:** Hero and workshop imagery are loaded from Unsplash and require an internet connection.
